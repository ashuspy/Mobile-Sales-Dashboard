
# 📊 Mobile Sales Dashboard (Power BI)

This project is a Power BI dashboard designed to provide clear insights into mobile phone sales. It allows users to monitor key performance indicators, analyze trends, and explore data interactively using various slicers and drillthrough functionalities.

---

## 📌 Project Objective

To design a dynamic and visually appealing dashboard that helps sales teams and business stakeholders:
- Track overall performance of mobile sales
- Compare sales across regions and time periods
- Identify top-performing products and underperforming areas
- Make data-driven decisions quickly and efficiently

---

## 🔧 Key Features

### 📅 Interactive Slicers
- **Date Range Selector**: Filter sales by specific timeframes
- **Region Filter**: Analyze data region-wise
- **Brand/Product Category**: Focus on specific mobile brands

### 📊 Visualizations Used
- **Bar Charts**: Compare product performance and regional sales
- **Line Charts**: Show monthly or yearly sales trends
- **Pie/Donut Charts**: Display share of sales by brand or region
- **KPI Cards**: Show high-level metrics like Total Sales, Profit, Units Sold

### 🔍 Drillthrough Functionality
- Users can click on any brand or region to navigate to a detailed product-level report.

### 🧠 Data Insights
- Identify best-selling mobile models
- Observe seasonal trends in sales
- Spot underperforming regions or brands

## 🛠 Requirements

- **Power BI Desktop** (Latest version recommended)
- No external data source required – sample data is embedded in the `.pbix` file

---

## 🚀 How to Use

1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
2. Open the `Mobile-Sales-Dashboard.pbix` file
3. Explore different pages and filters in the report
4. Customize visuals or add new ones as needed
